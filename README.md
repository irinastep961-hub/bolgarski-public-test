# Български — приложение для изучения болгарского

Next.js 15 + TypeScript + PWA. Без базы данных, авторизации, платежей и внешних API.

## Запуск
```bash
npm install
npm run dev        # http://localhost:3000, доступен и по Wi-Fi
npm run typecheck  # проверка типов
npm test           # тесты логики и контента
npm run build && npm start   # production-режим (включает PWA/офлайн)
# для разговорной практики и озвучивания лучше Chrome или Edge
```
Со смартфона: телефон и компьютер в одной Wi-Fi сети, откройте `http://<IP-компьютера>:3000`.

## Структура
- `src/types` — типы слов, упражнений, уроков, результатов, прогресса
- `src/content` — учебный контент (`words.ts`, `lessons.ts`) и сборщик упражнений (`build.ts`); без React
- `src/lib` — чистая логика: XP, серия, повторение (`progress.ts`), проверка текста, озвучка
- `src/storage` — `ProgressRepository` (интерфейс) и `LocalStorageProgressRepository`
- `src/components`, `src/app` — интерфейс
- `public` — манифест PWA, service worker, иконки

## Курс

Общение с соседями · 11. В парикмахерской и салоне красоты · 12. Покупка одежды и обуви · 13. В банке и при оплате счетов · 14. Свободное общение · 15. Глагол «съм» — быть (грамматический урок с таблицей спряжения, выбором формы, пропусками, отрицанием, вопросами с «ли» и пятью диалогами; около 30 упражнений).
В каждом уроке 8–10 слов, объяснения по-русски, около 17–20 упражнений.

## Разговорная практика (вкладка «Говорить»)
15 бытовых ситуаций (семь последних закрепляют уроки 8–14; сценарий «Разговор с приятелем» идёт на «ты»), в каждой диалог из 5–6 реплик (`src/content/conversations.ts`). Ответ можно печатать или говорить (браузерное распознавание речи, язык bg-BG; поддерживают Chrome и Edge, звук обрабатывает служба браузера). Ответы сверяются с шаблонами допустимых вариантов `{а|б|}` (`src/lib/conversation.ts`); ИИ не используется. Интерфейс `ReplyChecker` позволяет позже подключить AI-проверку. XP за реплику начисляется один раз (3 за первую попытку, 1 за исправление), повторное прохождение XP не даёт.

### Как проверяются ответы в диалогах
Ответ сверяется с шаблонами допустимых вариантов, плюс: «моля» и «ако обичате» необязательны там, где «моля» входит в сценарий; собеседнику говорят на «вы» (ошибки вроде «имаш» объясняются с учётом роли: продавец, врач и т. д.); повтор реплики собеседника распознаётся отдельно; равноценные естественные ответы помечаются `alsoNatural`, чтобы к верному ответу не приписывалось лишнее.

## Озвучивание
`src/lib/speech.ts`: болгарский текст читается только голосом с языком `bg`/`bg-BG`. Если такого голоса нет, ничего не произносится и показывается сообщение; русский голос не подставляется. Выбор голоса и инструкция по установке — страница «Успехи» → «Озвучивание» (`/voice`).
Ударения частотных слов — `src/content/stress.ts` (показываются в карточках слов, на странице «Озвучивание» есть список для самопроверки). Браузер не позволяет задать ударение отдельным параметром. В обычной работе слово уходит в голос без изменений; на экране ударение показывается из таблицы `stress.ts`. Эксперимент с знаком ударения U+0301 для слов из `SPEECH_HINT_WORDS` (`src/content/ttsHints.ts`) доступен как опция. Подсказка по умолчанию ВЫКЛЮЧЕНА: голоса Windows знак ударения не понимают и произносят слова хуже. Включить её для сравнения на слух можно на странице «Озвучивание».
Задел под записи носителей языка: добавить файл с записями и манифестом «id → файл» и проигрывать запись раньше синтеза речи (лицензия на записи обязательна).

## Типы упражнений
`choice` (выбор, в том числе выбор пропущенной формы `formChoices`), `translate` (болгарский → русский текстом), `build` (сборка фразы, допускаются варианты порядка слов), `type` (русский → болгарский с клавиатуры), `dialog` (реплика собеседника → выбор или ввод ответа).
Проверку ответов делает `src/lib/answer.ts`: регистр, пробелы и пунктуация не влияют на верность; принимаются только варианты из списка; при ошибке выводится объяснение по-русски (порядок слов, лишние/недостающие слова, опечатка, «ловушки» из описания урока).

## Как добавить урок
Добавьте слова в `src/content/words.ts` и описание урока в `src/content/lessons.ts` (`sentences` — фразы, `dialogs` — диалоги). Упражнения соберутся автоматически; `npm test` проверит целостность, в том числе что каждый допустимый вариант ответа принимается.

## Путь к облаку и подпискам
Новая реализация `ProgressRepository` (например, Supabase) подключается в `src/storage/index.ts`. Учебная логика и интерфейс не меняются.

> Тексты и ударения уроков 8–14 составлены без проверки носителем языка; перед публикацией их стоит показать носителю. Озвучка по-прежнему только болгарским голосом устройства.

## Урок 15: речевая практика «Говорим по-болгарски»

- Сценарий `govorim-sam` (10 вопросов приятеля на «ты») лежит в `src/content/conversations.ts` и открывается из урока 15 (карточка «Речевая практика к уроку») и из раздела «Говорить».
- Используется существующий механизм: `ConversationPlayer` + `VoiceInput` + `src/lib/recognition.ts` (Web Speech API, bg-BG). Нового кода микрофона нет.
- Ответ принимается по шаблонам с вариантами (род, порядок слов, «да/нет», краткие формы), буквального совпадения не требуется.
- Если распознавание не сработало (тишина, запрет микрофона, нет сети), показывается понятное сообщение и можно записать заново.
- Не проверено на реальном устройстве: микрофон и распознавание в Chrome/Edge, озвучивание реплик собеседника, `npm run build`.

### Исправление речевой практики (speech fix)

- Причина «съм свободна съм»: шаблоны образцов склеивались перекрёстно (`{Да, аз съм |}{свободна съм|…}`), и такие фразы попадали в список «верных» и в «исправленный вариант». Шаблоны исправлены, тест следит, чтобы в одном предложении не было двух форм «съм».
- Проверка свободных ответов: `src/lib/freeform.ts` (рамка `FreeSpec` у каждой реплики). Проверяются форма «съм», её место, «не», «ли», согласование и допустимые слова; слова вне списка не засчитываются «на глаз», приложение честно об этом пишет.
- Сообщения: «Отлично!» (ответ совпал с образцом), «Правильно! Можно сказать и так.» (свободный верный ответ).
- Не менялись: уроки 1–14, озвучивание, распознавание речи, дизайн, навигация, XP, прогресс.
